# 自転車ダッシュ

スマホのブラウザだけで遊べる、軽量な3D自転車障害物回避ゲームです。自転車、ライダー、道路、障害物、アイテムはコードで描画しているため、画像素材や外部3Dモデルは不要です。

## 起動

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 公開

このアプリはビルド不要の静的サイトです。`index.html`、`src/`、`vendor/`、`social-assets/`、`robots.txt`、`sitemap.xml`、`.github/`、`.nojekyll` をそのまま置けば公開できます。

### GitHub Pagesで公開する

1. このフォルダをGitHubリポジトリにプッシュします。
2. GitHubのリポジトリ設定で `Settings > Pages` を開きます。
3. 公開元を `GitHub Actions` にします。
4. `main` ブランチへプッシュすると `.github/workflows/pages.yml` が自動で公開します。

公開後は `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

### Netlify / Cloudflare Pagesで公開する

- ビルドコマンド: 空欄
- 公開ディレクトリ: `.`

サーバー処理は不要です。

## 検索向け設定

- `index.html` にdescription、OGP、Twitterカード、canonical、構造化データを設定しています。
- `social-assets/instagram-feed-1080x1350.png` をシェア用画像として参照しています。
- `robots.txt` と `sitemap.xml` はGitHub Pagesの公開URLに合わせています。

## できること

- 軽量な自転車とライダーの3D表示
- スマホ向けの大きな左右移動、ジャンプボタン操作
- スコア、レベル、コンボ、ラッシュ、ライフ、最高スコア表示
- コイン、防御アイテム、ライフ回復、ラッシュアイテム
- 神回避、パーフェクト、ニアミス、跳び越え、防御でコンボとラッシュゲージが伸びるスコアシステム
- 市街地、工事区間、橋、ジャンプ区間、トンネル、夜道へ切り替わる区間イベント
- 低い黄色バー、道路の切れ目、工事看板などの障害物
- ゲームオーバー時にランク、最高コンボ、神回避/跳び越え回数を表示するリザルト
- 小さなボーナス条件を順番に達成して報酬を得る要素
- レベル9999まで伸びる難易度
- 画面操作に影響されにくい固定寄りのプレイカメラ
- iPhone SE相当の小さいスマホ画面を最低表示幅として調整

Three.jsは `vendor/` 配下にローカル配置しています。

## 第三版の区間と障害物

- 市街地: 通常の道路です。
- 工事区間: 道路と路肩が黄色寄りになり、工事看板やバリアが混ざります。
- 橋: 外側が水辺っぽい青系になり、通れるレーンが狭く感じる配置が増えます。
- ジャンプ区間: レーン線が明るい水色になり、低い黄色バーや道路の切れ目など、ジャンプで越える障害物が増えます。
- トンネル: 画面全体が暗めになり、上をくぐる障害物とジャンプ障害物の判断が混ざります。
- 夜道: 背景と道路がさらに暗くなり、難しいぶんスコア倍率が高くなります。

ジャンプ専用障害物は、低い黄色バー、道路の黒い切れ目、穴系の障害物です。ジャンプで越えると跳び越えとして加点され、スレスレで避けると神回避やパーフェクトにもつながります。
